1. **Download** - Get this template from the Bulk Import modal

## ⚠️ Important Notes

- Package names must be unique
- If a package exists, it will be updated
- Prices should not include commas
- Freezable accepts: Yes, No, true, false
- Discount Type: "flat" for amount, "percentage" for %
- Leave optional fields empty if not needed
